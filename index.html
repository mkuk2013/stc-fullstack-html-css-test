⚠ Examination Policy

Strict Test Rules

Ye rules har student par lagu hain. Kisi bhi khilaf-warzi par test khud-kar cancel ho jayega — koi warning dobara nahi milegi.

🔁 One-Time Attempt

Har student sirf EK dafa test de sakta hai. Ek dafa start / submit / cancel ke baad dobara attempt system khud block kar dega.

🚫 Tab / Page Change = Cancel

Test ke doran tab change, browser minimize, ya dusri app/page kholne par test foran CANCEL ho jayega.

❌ Page Close / Refresh = Cancel

Page band ya refresh karne par bhi test cancel ho jayega aur aap ki attempt record ho jayegi.

🖥 Full-Screen Mode

Poora test full-screen mein hoga. Full-screen se bahar nikalna bhi cancellation ki wajah banega.

⏱ 100 Minutes Fixed Time

100 sawalon ke liye kul 100 minutes. Time khatam hote hi test khud submit ho jayega — extra time nahi milega.

📵 No Copy / Paste

Test ke doran copy, paste aur right-click band hai. Apne jawab khud sochein — ye aap ki asal progress ka imtihan hai.
